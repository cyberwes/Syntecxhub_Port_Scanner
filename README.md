# Syntecxhub_Port_Scanner
Multithread TCP port scanner 
Simple Threaded Nmap Port Scanner (Python)
🔍 Description
This is a beginner-friendly Python port scanner that uses Nmap to scan TCP ports on a target host.
It supports single ports or port ranges and uses basic threading to improve scan speed.
This project was built to learn:
Basic networking concepts
Port scanning
Python threading
Automating security tools with Python
⚙️ Features
Scan a single port or a range of ports
Clear output showing OPEN and CLOSED ports
Uses Nmap (industry-standard scanning tool)
Simple threading for faster scans
Logs scan results to a text file
🛠 Requirements
Python 3
Nmap installed on the system
python-nmap library
Install the Python dependency:
Copy code
Bash
pip install python-nmap
▶️ How to Run
Copy code
Bash
python threaded_nmap_scanner.py
Enter:
Target IP or hostname
Port or port range (example: 22 or 20-80)
📄 Output
Results are printed to the terminal
Scan results are saved to scan_results.txt
